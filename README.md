# Image Fragmentator 7.7.0

Local image processing and GrainSight/FastSAM-assisted segmentation for petrographic images. Runs as an R Shiny application in a web browser.

This compact Windows distribution separates the application from its dependencies. The release ZIP includes source code, installation scripts and license notices. R packages, the optional isolated Python CPU runtime and the model are downloaded during setup. No personal images or calibration records are included.

Start with [START_HERE.md](START_HERE.md). Make Thin Section V70 Lite can launch the separately installed program using `fragmentator_path.txt`.

Base installation: `1_Install_dependencies.cmd`. Launch: `2_Start.cmd`. Optional AI installation: `3_Install_AI.cmd`. Check: `4_Check_installation.cmd`.

See [third-party notices](app/THIRD_PARTY_NOTICES.md) for component licenses and attribution.
